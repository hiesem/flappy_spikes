## Run on Linux (test only)

Android and iOS are the products; the Linux desktop build is a local test target
(a phone-shaped, non-resizable window). From this directory:

```bash
flutter run -d linux
```

- Debug panel (debug builds and Linux only): long-press the home title, or press `D`.
- Keys: `Space` / `Enter` = START (and flap during a run), `Esc` = back.
- Linux audio needs `gst-plugins-good` (see `TODO.md`).
